# 09. Голос: текст распознавания из локального IPC Алисы

Станция распознаёт речь в облаке, но **готовый текст отдаёт в локальный сокет**. Значит свои
команды можно привязывать к голосу, не трогая микрофон, модели и облако: достаточно прочитать
то, что Алиса и так услышала.

## Где и что слушает

```sh
netstat -ln | grep 9875      # 127.0.0.1:9875 — слушает maind
```

Рядом живут ещё десяток портов `9850–9899` (другие сервисы `maind`), но нам нужен именно 9875.

## Формат

TCP, кадр = **4 байта длины (little-endian)** + protobuf-сообщение:

* поле `253` (varint) — тип сообщения, `3` = состояние Алисы (`AliceState`);
* поле `252` (bytes) — вложенное сообщение состояния, в нём:
  * поле `1` (varint) — статус: `3` = **финальное** распознавание;
  * поле `2` (bytes) — сам текст;
  * поле `7` — идентификатор запроса;
  * поле `15` — структура ASR.

Обратно в тот же сокет можно отправлять команды (тем же кадром, поле `252` = вызов,
`253` = 210). Например, отменить разговор Алисы — чтобы она не начала свой ответ поверх нашей
музыки: `rpc("AliceCapability", 8, [8, 3])`.

## Что это даёт

* «Включи Звук» → запустить свой плеер, без своих моделей и без облачных навыков.
* Отменить штатный ответ Алисы на эту фразу.
* Слушать, что вообще говорят колонке (осторожно: это персональные данные).

## Слушатель

[`scripts/device/alice-voice.sh`](../scripts/device/alice-voice.sh) — живёт на колонке:

1. подключается к `127.0.0.1:9875` через `socat -u` (**важно: `-u`**, иначе socat закрывает
   соединение по EOF на stdin и слушатель крутится вхолостую);
2. читает кадры: `dd bs=4 count=1 | od -An -tu4` → длина, затем `dd bs=<длина>`;
3. ищет в кадре любую фразу из `/data/local/etc/voice-triggers.txt` (`grep -F` по байтам);
4. помнит последнюю сработавшую фразу в `/tmp/alice-voice.last` — одно распознавание приходит
   в нескольких кадрах подряд, без этого действие сработает 2–3 раза;
5. действие — функция `hook()` в скрипте (сейчас только пишет в
   `/data/local/tmp/alice-voice.log`).

Автозапуск — строка в `/etc/init.d/S97station-root`.

## Грабли

| Симптом | Причина | Лечение |
|---|---|---|
| Лог полон «соединение потеряно» | `socat` без `-u` видит EOF на stdin и рвёт канал | `socat -u TCP:127.0.0.1:9875 -` |
| Фраза не ловится, хотя сказана | сравнение побайтовое, «Включи» ≠ «включи» | шаблоны без первой буквы: «ключи звук», «мой плеер» |
| Одно действие — два-три раза | текст приходит в нескольких кадрах (partial + final) | дедупликация по фразе и времени |
| Порт «не слушается» снаружи | он привязан к `127.0.0.1`, так и должно быть | мост `socat TCP-LISTEN:...,fork TCP:127.0.0.1:9875` только на время отладки и только в своей сети |
